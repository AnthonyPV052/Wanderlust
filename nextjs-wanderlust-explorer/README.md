# Wanderlust Explorer

Aplicación de descubrimiento de experiencias de viaje con un diseño moderno y minimalista.
Usa una paleta neutra (zinc) con acentos **indigo** para acciones y **amber** para ratings.
Tarjetas con esquinas redondeadas, sombras suaves y transiciones hover dan un estilo limpio.
Soporte automático de dark mode, tipografía Geist y layout responsivo de 1 a 4 columnas.
Filtros sincronizados con query params en la URL para compartir búsquedas fácilmente.
